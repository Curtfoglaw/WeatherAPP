# WeatherAPP
A full‑stack Flask weather application that lets users search for real‑time weather data, store search history, and access their information across sessions. Built with Python, Flask, SQLAlchemy, and deployed using Gunicorn on Render.

# Live demo
https://weatherapp-xh4x.onrender.com/

# Features
- search weather by city using a live weather API
- displays temperature and conditions
- user authentication with Flask-login
- SQLite database for storing user accounts and search history
- HTML/CSS UI
- fully deployed using Gunicorn on Render
- secure environment variable handling with python-dotenv

# Tech stack
- Backend: Python, Flask, Flask-login, Flask-SQLAlchemy
- Database: SQLite
- Frontend: HTML, CSS, Jinja2 templates
- Deployment: Render, Gunicorn
- API: Weather API
